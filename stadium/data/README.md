# Citi Field OpenStreetMap snapshot

`citi-osm.json` is a snapshot of mapped pedestrian ways, parking aisles, and building footprints around Citi Field, retrieved from the [OpenStreetMap map API](https://wiki.openstreetmap.org/wiki/Api06) on 2026-09-22. The underlying map data is © OpenStreetMap contributors and is available under the [Open Database License 1.0](https://www.openstreetmap.org/copyright). The repository's source code license does not replace this data license.

The snapshot includes 149 pedestrian and parking aisle ways, 444 path nodes, and 30 building or venue footprints. It is a public map extract, not a venue-authorized routing or access plan. The three perimeter entry points used by the simulation are approximate path nodes.
